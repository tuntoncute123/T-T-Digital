# T&T Digital - Landing Page Doanh Nghiệp Thiết Kế Website & Giải Pháp Phần Mềm

Dự án Landing Page chính thức cho **T&T Digital** - Đơn vị tư vấn, thiết kế website cao cấp và phát triển giải pháp phần mềm quản trị doanh nghiệp may đo theo yêu cầu.

---

## 1. Nền Tảng Công Nghệ & Thư Viện

- **Framework**: Next.js 16 (App Router) & React 19
- **Ngôn ngữ**: TypeScript 5 (Strict type safety)
- **UI & Component System**: Ant Design (antd ^6.6.7) với Ant Design Icons (@ant-design/icons ^6.3.4)
- **Styling**: Tailwind CSS v4 kết hợp Vanilla CSS Micro-Animations
- **Icon System**: Lucide React (^1.61.0)
- **Hiệu ứng Cuộn Trang**: AOS (Animate on Scroll ^2.3.4)
- **Hiệu ứng Chúc mừng Form**: canvas-confetti (^1.9.4)
- **Typography**: Google Fonts Plus Jakarta Sans (Hỗ trợ 100% tiếng Việt chuẩn UTF-8)

## 3. Tuân Thủ Quy Chuẩn & Bảo Đảm Kỹ Thuật

- **Chuẩn Tiếng Việt UTF-8**: Đảm bảo 100% hiển thị không lỗi font chữ, sắc nét.
- **Responsive Hoàn Hảo**: Tương thích mượt mà từ màn hình Mobile (375px), Tablet (768px), Laptop (1024px) đến Desktop lớn (1440px+).
- **Tuân thủ quy định dự án**:
  - Không sử dụng icon Tên lửa (🚀).
  - Không sử dụng icon Sparkles / Ngôi sao lấp lánh (Sparkles SVG).
  - Không hiển thị tên thư viện kỹ thuật lên mặt giao diện khách hàng.
  - Sử dụng hệ thống icon công nghệ chuẩn mực: `Globe`, `Cpu`, `Smartphone`, `Layers`, `ShieldCheck`, `Zap`, `CheckCircle2`, `Calculator`, `Code2`.

## 4. Hướng Dẫn Chạy Dự Án

### Khởi động môi trường phát triển (Development):
```bash
npm run dev
```
Sau đó truy cập: `http://localhost:3000`

### Kiểm tra cú pháp & Types:
```bash
node "node_modules/typescript/bin/tsc" --noEmit
```

### Đóng gói ứng dụng (Production Build):
```bash
npm run build
```
